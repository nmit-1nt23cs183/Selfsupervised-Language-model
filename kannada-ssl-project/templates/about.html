Kannada SSL

Self-Supervised Learning for Low-Resource Kannada Language Processing

🌐

What it does

Translates text or speech from any language into Kannada internally using a self-supervised ML model, then delivers the result in your desired language.

🎙️

Speech Recognition

Speak into your microphone in any language. The system auto-detects your language, processes it through the Kannada SSL model, and outputs in your chosen language.

⌨️

Virtual Keyboard

Type directly in Kannada script using the on-screen keyboard — no special input method needed. Supports Kannada vowels, consonants, and conjuncts.

🧠

Self-Supervised Learning

The core model is trained on Kannada audio and text using SSL (wav2vec2 + mBERT) — no large labeled datasets required, making it ideal for low-resource languages.
